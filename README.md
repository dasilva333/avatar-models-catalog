# 🎭 Ultimate Avatar Models Catalog

A comprehensive, curated catalog of Live2D and Spine 2D/3D character models harvested, decrypted, normalized, and categorized for interactive avatar applications (Airi, LPK Studio, VSeeFace, WebGL renderers).

## 🛠 Features

- **Normalized English Titles & Metadata**: All original CJK/Asian titles translated and normalized into clean English titles while preserving original titles in descriptions.
- **Danbooru Character Tags**: Integrated multi-tag search (character features, outfits, game series, anime origins).
- **WebGL Preview Compatibility**: Pre-tested for compatibility with Live2D Cubism WebGL SDK & Spine Web Player.
- **Proven Provenance**: Includes original Steam Workshop IDs, creator attributions, and subscription metrics.
